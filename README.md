# Stormwind Life

A Sims-style life game set in Stormwind: rent a room, get a job, make friends, fall in love,
fish, dive for the Sunken Kingdom, fight in dungeons... and get ready before Deathwing returns.

**Play:** open the GitHub Pages link for this repository (or download it and double-click `index.html`).
Works in Chrome, Edge and Firefox on a computer. Keyboard and mouse, or a controller.
